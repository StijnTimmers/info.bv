# E&S Software (info.bv)

**E&S Software** ontwikkelt slimme software voor schoolkantines. Onze applicatie is gebruiksvriendelijk voor zowel kantinemedewerkers als leerlingen (kopers). Dankzij onze handige bestelfunctie kunnen leerlingen vooraf hun lunch bestellen, waardoor lange wachtrijen en drukte in de pauze worden vermeden.
